# Rubric 1.1 — material-based mandatory grading

The five-level definitions originate in the user image `assets/rubric.png`. On 2026-11-10 the user explicitly required a grade for every person and removed auditing. This revision supersedes rubric 1.0's universal “no caught errors, no pass” gate and null/abstention policy. Do not call it an unchanged transcription of the image. Apply the same revised policy to everyone; old results require fresh scoring to migrate.

| Level | Evidence sought |
|---|---|
| Assisted | AI assists with pieces: questions, drafts, search, prompts, images or individual production steps. Also the explicitly provisional floor if evidence cannot support any substantiated level. |
| L1 Delegator | Gives AI a complete bounded task, then checks output. A whole script, report, deck or complete asset set qualifies. Personally combining many AI-assisted steps alone does not establish whole-task delegation. Checking need not include an actual caught-error incident. |
| L2 Operator | A setup runs on its own for 8+ weeks, catches its own errors, and has one measured result. All three conditions matter; manual review is not automatic detection. |
| L3 Builder | Built a system the team uses every week and a team metric improved. Routine team use must be described, not inferred from a lead title, team size or generic SOP. |
| L4 Architect | Redesigned a whole function with AI and the company would notice within days if it stopped. Need support for scope and dependency; never require a harmful shutdown. |

Choose the highest level supported by current material, not a dimension average. Specific coherent self-report can support a material-based rating without external certification; label it and qualify confidence. Generic slogans or numbers without relevant context cannot establish a higher-level condition.

Missing actual AI error examples are evidence limits, not a universal veto or automatic downgrade. L2's automatic error handling remains an explicit condition. L3/L4 do not inherit L2's eight-week requirement. No invented improvement thresholds, universal logs, weights or 100-point scale.

If evidence is absent, unreadable, contradictory or too generic to support ANY main definition, still output Assisted with `rating_status=provisional`, `confidence=low` and concrete `evidence_gaps`. The HR reason and level explanation must call this the lowest provisional material-based placement, not observed or disproven competence. Never assign a higher grade merely to satisfy mandatory grading. Clear part-task AI use can support Assisted without provisional status.

`rating_status=supported` means supported by submitted material under this policy, NOT externally verified. `confidence=high|medium|low` describes evidence strength, not level or hiring desirability. Missing evidence is not proof of inability. Ignore demographics, appearance, prestige, tool count and other candidates. No hiring recommendation.
